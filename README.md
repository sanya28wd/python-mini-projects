# Python Mini Projects

A curated collection of terminal games, simulations, and Turtle graphics projects built while strengthening my Python fundamentals.

## Projects

| Project | What it demonstrates | Run command |
| --- | --- | --- |
| [Blackjack](projects/blackjack) | Pure game logic, collections, input validation | `python projects/blackjack/blackjack_game.py` |
| [Coffee Machine](projects/coffee_machine) | Resource management, transactions, typed data | `python projects/coffee_machine/coffee_machine.py` |
| [Hangman](projects/hangman) | Modular data, state management, string processing | `python projects/hangman/hangman_game.py` |
| [Pong](projects/pong) | Turtle graphics, keyboard events, collision detection | `python projects/pong/pong_game.py` |
| [Turtle Race](projects/turtle_race) | GUI input, animation, randomness | `python projects/turtle_race/turtle_race.py` |
| [Caesar Cipher](projects/caesar_cipher) | Reusable functions and text transformation | `python projects/caesar_cipher/caesar_cipher.py` |
| [Number Guessing](projects/number_guessing) | Difficulty levels and bounded game loops | `python projects/number_guessing/number_guessing_game.py` |
| [Turtle Art](projects/turtle_art) | Procedural drawing and colour generation | See the project README |

## Requirements

- Python 3.11 or newer
- Tk support for the Turtle projects (included with most standard Python installations)

No third-party packages are required.

## Running a project

Clone the repository, move into its directory, and run any command from the table above.

## Background

These projects were rebuilt and reorganized from exercises completed while following Dr. Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp*. The repository contains only the curated implementations, not the course scaffolding or supplied lesson files.
